# Superseded material

This directory preserves the repository before the November 2026 lifecycle
refresh: article plans and drafts, platform research, original images, Office
exports, and the old companion. Original relative layout is retained where
possible so attribution and provenance remain available.

**Not current guidance.** These files contain outdated API combinations,
inconsistent thresholds/status claims, incomplete examples, and an evaluation
gate that can pass without sufficient evidence. Do not execute or distribute
them as the maintained implementation.

Current guidance starts at [the repository README](../README.md). Replacements
are recorded in [the migration map](../references/migration.md). The archive is
excluded from the current catalog, publishing, and local-link acceptance checks.
Its content is preserved rather than silently "corrected" into a new historical
record.
