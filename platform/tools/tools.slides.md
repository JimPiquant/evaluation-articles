# A schema is not a tool

- Definition guides model choice
- Implementation executes behavior
- Authorization constrains access
- Independent record proves effect

# Know the contract

- Function calling
- OpenAPI-backed service
- MCP server
- Different execution/authentication boundaries

# Exercise the real candidate

- Actual endpoint/version
- Input and output schema
- Allowed and denied operations
- Timeouts, errors, repeated calls

# Use the fixture harness honestly

- Working local support tools
- Synthetic customers
- Deterministic effects
- Not a live CRM or semantic judge

# Add conversation evidence

- Tool definitions and messages
- Calls, arguments, results
- Tool Use Quality and compatible criteria
- Business rubric and exact outcomes

# Centralize the gate

- Configure every required evaluator
- No missing utilization-as-pass
- Normalize score versus pass-rate
- Preserve actual tool/application attribution

# Promote the pair

- Compatible application and tool versions
- Isolated evaluation effects
- Retained acceptance evidence
- Rollback for incompatible contract
